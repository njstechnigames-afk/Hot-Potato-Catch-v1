# Hot-Potato-Catch-v1:
This is a game I've worked on for the hackathon. It is a space potato themed game with 2 minigames to play with.

There is a death and winner screen that all work (I've tested it (yes I've sat there for 1 minute to lose just to see if it works))

# Controls:
-minigame 1: left & right arrow keys to move, space to jump

-minigame 2: click dem potatos :). 

# AI usage:
AI was ussed to help export the project.
